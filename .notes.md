In an Express backend , there are a few important components :

1. Routers
    Only job is to answer which route calls which controller
    

2. Controllers
    Controllers are the HTTP bridges between the client request and the business logic which resides in Services. 
    - It's main responsibility is 
    - Read information from request
    - Call the required service
    - Build the HTTP response to send back
